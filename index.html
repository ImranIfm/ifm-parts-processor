Spare-parts documentation

Turns a raw Comac catalogue into a finished parts document.

Comac drawings label every callout with a balloon number; the real part codes sit in a table on the next page. Drop in one PDF and the Processor stamps the real code onto every callout, links it, extracts the drawings and builds a priced spreadsheet.
