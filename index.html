IFM Comac Parts Processor

Internal desktop tool · Windows

v9.7.3
Spare-parts documentation

Turns a raw Comac catalogue into a finished parts document.

Comac ships exploded parts drawings where every callout is just a balloon number, and the real part codes sit in a table on the following page. Matching them by hand is slow and easy to get wrong. The Processor does the whole chain — reads the drawing, writes the real code onto every callout, links each code to its catalogue entry, pulls the images out, and produces a priced spreadsheet — from one dropped PDF.

What it runs

Four stages. Run them one at a time, or switch on Auto-Pilot and it works through all four back-to-back.

01

Code Replacement

Reads each exploded drawing, finds every balloon callout, matches it against that diagram's own parts table and stamps the real eight-digit part code in its place.

02

Hyperlinks

Makes every stamped code clickable, pointing at the matching entry so the document can be navigated instead of cross-referenced.

03

Image Extraction

Pulls the drawings out as individual image files, ready to attach to catalogue or web listings.

04

Excel Report

Builds a spreadsheet of every part found, costed against the master Comac price list, converted from euros to sterling at a live or fixed rate, with Italian descriptions translated to English.

Also handles

Older catalogues don't follow the current layout, so stage 01 has a second engine built for them.

ALT

Old PDFs Processor experimental

A variant of stage 01 for the older and scanned catalogues — landscape drawings, tables with no ruled boxes, rotated pages, and scans with no usable text layer, which are read by OCR.

LOG

Job history

Every run is kept with its counts and output folder, so a job can be reopened, checked or re-exported later.

Download

The build is stored encrypted. Your credentials derive the key that decrypts it in your browser — there is no link to copy and nothing to download without them.

Encrypted with AES-256-GCM; the key is derived from your credentials using PBKDF2-SHA256 at 600,000 iterations, in the browser. Nothing is sent anywhere — payload.bin is fetched and decrypted on your own machine.
